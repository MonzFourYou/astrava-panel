# Contributing

Terima kasih telah ingin berkontribusi pada Astrava Panel.

## Cara Berkontribusi

1. Fork repository.
2. Buat branch baru.
3. Commit perubahan.
4. Push ke GitHub.
5. Buat Pull Request.

---

## Coding Style

- Gunakan HTML5.
- Gunakan CSS yang rapi.
- Gunakan JavaScript ES6.
- Beri komentar pada kode yang penting.
